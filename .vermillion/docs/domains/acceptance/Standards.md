# 验收实例隔离与清理

验收实例同时使用独立的应用数据目录和独立的测试项目目录。只注册新建测试项目或隔离副本，不注册用户真实项目，不复制或链接真实项目的工单、调度等运行记录。启动后核对 dataDir 和已注册 workspace 的绝对路径，再开始操作。

Worker 向 Verifier 提供实例 pid、CDP 地址、dataDir 和测试项目绝对路径。Verifier 操作前核对隔离，路径缺失或不符合隔离要求时停止验收并反馈 Worker。

浏览器连接使用任务专用 session。验收成功、失败或中断时均关闭该连接；实例创建者调用 app.stop，确认进程退出且调试端口释放后再提交最终结果。不关闭用户实例或其他任务的实例。
