# Issues

Issue 是用户提出或 agent（Maintainer、Liaison）收集的议题。状态有待处理、已开工、关闭、重复。Issues 入口显示未读数量。议题本身不触发开发，经工作台会话讨论后开工，或由用户手动建单。

## 列表与详情

点击议题以弹窗打开详情，保留底层页面的筛选和位置。“进入讨论”关闭弹窗并切换至关联会话。

工作台 → Issues 按标题栏选择的 workspace 展示议题，默认显示待处理项，支持标题搜索、状态与领域筛选及手动新建。列表显示标题、来源、领域、状态、更新时间与未读标记。

详情展示问题与影响、要求依据、证据及验证程度、建议方向和活动记录，并关联来源巡检会话、讨论会话与工单。已有 Issue 支持持续补充证据和活动；问题归并规则由对应收集角色的 prompt 定义。

## 讨论与处理

详情中的“进入讨论”在工作台会话页创建关联的设计伙伴会话，带入问题、依据与证据；已有讨论时入口为“继续讨论”。用户在会话中明确预期与方案后开工，工单回链 Issue，议题状态变为已开工。讨论本身不改变待处理状态。保留用户手动建单并关联议题的能力。

用户可关闭议题或标记重复并关联原议题，保留处理原因。已接受的取舍供 Maintainer 后续检查参考，避免重复提报。

Issue 的创建、查询、更新、关联讨论与工单，以及领域巡检配置、触发和记录查询均提供 CLI 调用路径。
