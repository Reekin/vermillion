# 手机远程

用户在 iPhone 上查看和操作正在运行的桌面 Vermillion：浏览会话列表、阅读会话并发消息、处理 Inbox，需要用户处理时收到推送。一部手机可以连接多台桌面（如一台 Mac、一台 Windows PC），每台桌面单独配对，手机上切换到某台桌面后查看它的内容。桌面端不限 macOS 或 Windows。

## 连接方式

桌面在本机开启远程入口，通过 frp 隧道把它映射到用户自己的 VPS；VPS 上的 Caddy 提供 HTTPS，证书可以签给 VPS 的 IP 地址，不要求域名。每台桌面在 VPS 上占一个端口，手机通过 `https://<VPS 地址>:<端口>` 访问对应桌面。

远程入口随桌面 Vermillion 运行：桌面退出、电脑休眠或隧道断开时，手机上该桌面显示离线，恢复后自动重新连接并补齐离线期间的变化。

仓库提供 VPS 一键部署脚本和部署说明：在 VPS 上安装并配置 frps 与 Caddy，按桌面数量开放端口，并说明 VPS 防火墙、桌面端 frpc 安装（含 Windows Defender 排除）与电脑防休眠设置。

## 桌面设置 · 远程访问

设置弹窗中新增「远程访问」区块，单值配置改动即保存：

- **远程访问开关**：开启后桌面启动远程入口并拉起隧道；关闭后停止隧道，已连接的手机立即断开。
- **隧道**：VPS 地址、frp 服务端口、frp token、这台桌面在 VPS 上使用的端口；frpc 程序路径的选择与恢复默认规则同[引擎程序路径](../../Foundation/Engines/PRD.md#设置)。
- **公网地址**：手机访问这台桌面的地址，默认由 VPS 地址和端口组成，可改为域名地址；写入配对二维码。
- **桌面名称**：手机桌面列表中显示的名称，默认取计算机名。
- **状态**：显示隧道已连接，或连接失败的具体原因。
- **配对新设备**：弹窗显示二维码和 8 位配对码，10 分钟内有效，只能使用一次；配对成功后弹窗显示设备名并关闭。
- **已配对设备**：列出设备名、配对时间、最近连接时间、推送是否可用；移除设备后它立即断开，之后不能再连接，需要重新配对。
- **推送**：APNs 密钥文件（.p8）、Key ID、Team ID、App Bundle ID；提供「发送测试推送」，结果在行内显示。

## 手机端

手机端由 iOS App 和手机网页组成。App 负责桌面列表、配对、推送和通知跳转；会话列表、会话和 Inbox 页面由各台桌面提供，所以手机页面总是与所连桌面的版本一致，更新桌面即可更新这些页面。

### 桌面列表

App 首页列出已配对的桌面：名称、在线状态、Inbox 待处理数。点击进入该桌面的会话列表；在桌面内可随时返回列表切换到另一台。「添加桌面」通过扫描桌面设置里的二维码，或手动输入公网地址和配对码完成配对；配对凭据保存在 iPhone 钥匙串中。桌面可从列表中移除。

### 会话列表

进入桌面后默认显示会话列表，顶部可切换到 Inbox，并显示 Inbox 待处理数。列表的排序、状态灯和相对时间与[桌面会话列表](../Think/PRD.md#会话列表)一致，可按 workspace 筛选，「全部」下显示 workspace 名。一棵会话树占一行，点击打开该树当前查看位置所在的会话。手机上不提供重命名、置顶、归档等行操作，也不展开 subagent。

### 会话

按时间顺序显示会话树当前路径上的消息，运行中的内容实时更新。工具调用和终端输出默认折叠为一行摘要，点开查看。

底部输入框只接受文字，消息发送到当前路径的末端节点；运行中可以停止当前轮次，也可以继续发送（按引擎的 steer 行为处理）。等待审批或等待输入时显示对应请求，可直接批准或拒绝。会话状态（就绪、运行中、等待审批、失败）显示在输入框上方。

会话页不提供节点跳转、fork、模型和推理配置、附件、技能选择。

### Inbox

只显示待处理项，内容与[Inbox](../Inbox/PRD.md)相同：

- **决策卡**：问题、上下文、选项及影响、推荐项和理由直接可见，技术详情折叠。可选择选项并附说明提交，也可只写文字自由答复。
- **已合入通知**：工单标题、证据摘要和逐条验收结果，「知道了」标记为已处理。
- **工作受阻通知**：原因和关联工作。

每项提供「进入会话」，打开发起它的会话。回滚、合入重试等处置操作留在桌面完成；已处理记录不在手机上显示。

### 推送

推送的触发条件与[桌面提醒](../Think/PRD.md#桌面提醒)相同：用户自己的会话完成一轮，或 Inbox 出现新的决策卡、已合入通知、工作受阻通知。桌面窗口不在前台，或桌面超过 5 分钟没有键盘鼠标操作时才发送，用户正在桌面前工作时手机不打扰。

推送标题标明来自哪台桌面。点击推送打开该桌面，并定位到对应会话或 Inbox 项。多台桌面使用同一个 APNs 密钥，各自向已配对且登记了推送的设备发送。

### 浏览器访问

在手机浏览器中直接打开桌面的公网地址也可以使用：输入配对码完成配对后，提供相同的会话列表、会话与 Inbox。浏览器访问没有推送和多桌面列表。

## 安全

远程入口只接受已配对设备的连接，只开放本文列出的查看与操作，不能通过它修改文档、设置或执行其他工作台操作。所有访问都经过 HTTPS。配对码输错 5 次即作废，需要在桌面重新生成。

## CLI

| 方法 | 作用 |
| --- | --- |
| `remote.status` | 远程入口、隧道、推送配置状态和已连接设备数 |
| `remote.configure` | 读取或修改远程访问设置，与设置页相同 |
| `remote.pair` | 生成配对码，返回配对码、二维码内容和有效期 |
| `remote.device.list` | 列出已配对设备 |
| `remote.device.revoke` | 移除设备并立即断开 |
| `remote.push.test` | 向指定设备发送测试推送 |

## 明确不做什么

手机上不提供文档、工作、领域、角色、Issues、自动化、管理等分页，不提供搜索、设置、新建会话、附件和会话树导航。不把多台桌面的会话或 Inbox 合并成一个列表。不开发 Android App，不自建中继服务，推送只支持 APNs。
