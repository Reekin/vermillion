# 手机远程实现规范

产品行为见[手机远程](PRD.md)，模块边界见[架构 · 远程访问](../../Foundation/Architecture.md#远程访问)。

## 鉴权与暴露面

- 远程网关只监听 loopback，公网流量只能经隧道进入；TLS 在 VPS 的 Caddy 终止。
- 每台设备配对后获得一个随机长期凭据（至少 256 位），桌面只保存其哈希。HTTP 请求与 WebSocket 连接在处理任何业务前校验凭据，失败直接拒绝；移除设备时关闭它的全部连接。
- 配对码一次性、10 分钟有效，失败 5 次作废；配对接口是未鉴权状态下唯一可调用的业务接口。
- 网关按方法白名单转发，白名单只包含手机页面实际使用的只读查询、会话发送/停止/审批、决策答复与通知确认；白名单外的方法返回拒绝，不以界面隐藏入口代替。
- 凭据、APNs 密钥内容和消息正文不写入日志；APNs 设置只保存 .p8 文件路径。

## 连接与同步

- 手机页面与桌面 renderer 使用同一套会话 RPC、事件与工作台 RPC 契约，不为手机另建一套查询或投影。
- 一条 WebSocket 连接承载请求响应与事件推送；每个连接独立持有订阅，断开时释放。重连后按事件 cursor 回放补齐，出现断档时重新拉取快照。
- 页面进入后台被系统挂起属于正常断线，回到前台时静默重连，不显示错误。

## 平台

- 推送直连 APNs（HTTP/2 + .p8 签名 JWT），使用 Node 内置能力，桌面端在 macOS 与 Windows 上行为一致；按设备登记的环境区分 sandbox 与 production。
- frpc 由桌面按设置生成配置并作为子进程运行，随远程访问关闭或应用退出而结束；程序缺失或启动失败时在状态中显示原因。
- iOS App 只承载桌面列表、配对、推送登记与通知跳转，会话与 Inbox 页面由桌面提供；原生改动才需要重新发版。

## 验收

- 远程链路的验收在隔离实例中进行，本机运行 frps 与 Caddy（本地证书）模拟 VPS，覆盖配对 → 会话列表 → 打开会话 → 发送并看到流式回复 → Inbox 答复 → 移除设备后连接被拒。
- 手机页面用移动端视口（如 390×844）截图核对，iOS App 在 iOS 模拟器中核对配对、切换桌面和加载页面；APNs 真实送达需要真机时，以测试推送接口返回 APNs 成功响应作为证据，并说明真机步骤。
