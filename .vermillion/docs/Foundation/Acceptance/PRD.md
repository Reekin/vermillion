# 隔离实例准备

## 要做什么

`app.start` 接收独立 `dataDir` 与 CDP `port`，可选择 `fixture: "session-tree"` 或 `fixture: "real-session"`，一次完成隐藏桌面启动及对应环境准备。成功返回前确认本次进程的 CDP 与工作台 RPC 就绪；选择 fixture 时，测试项目也已通过正常查询确认注册。

`session-tree` 提供一个父会话、一个归属正确的子会话及一个没有子会话的普通会话。列表通过正常查询与渲染路径显示这些记录，支持展开、折叠和打开会话阅读固定历史内容；准备过程不调用模型、不启动 Worker 或创建执行工单。

`real-session` 提供独立 Git 测试项目及起始提交，接入真实 Codex。首次准备在 dataDir 内建立独立 CODEX_HOME，只从 `codexConfigSource` 指定的目录读取运行所需配置、认证及模型目录相关文件；未指定来源时使用调用端当前 Codex 配置目录。复用调用端可用的引擎程序及连接配置，历史、数据库、日志与其他可变状态均写入隔离目录，不复制用户会话、工单或项目。模型目录可用后返回；不自动发送模型消息、创建设计会话或派发 Worker。调用者通过现有 GUI/CLI 创建本单所需真实会话和工单，停止、重启、fork 与继续发送沿用正常产品行为。

同一 dataDir 重启沿用已有隔离配置、Git 历史、注册项目和会话，不重新生成或覆盖。准备所需条件缺失时返回具体原因，不能以空模型目录或固定历史后端代替真实环境成功返回；创建进程后准备失败则停止该次进程。

结果包含 `pid`、`cdpUrl`、`desktop`、绝对路径 `dataDir`，fixture 另返回 `projectPath` 和 `workspaceId`，真实环境另返回 `codexHome`；可用现有 `runtime.info` 核对所运行构建。停止沿用 `app.stop`。不指定 fixture 时不预置测试项目，调用者按隔离规范自行提供环境。

### 候选与连接目标

启动明确指定被测源码 checkout 或发布产物目录，并绑定预期构建身份。源码候选在指定目录准备并核对验收所需构建产物；产物缺失、过期或实际运行身份不符时不返回验收就绪。当前工作目录或全局 CLI 的安装位置不替代被测目标。

成功结果同时给出被测目录、实际构建身份、实例身份和可直接复用的定向 CLI 调用信息。使用该调用信息的查询与操作只连接指定实例；目标已退出或身份不匹配时明确失败，不转接用户实例或本地离线服务。真实引擎环境返回实际使用的状态目录与非敏感环境参数，包含 CODEX_HOME、CODEX_SQLITE_HOME 等，使外部 CLI 与验收实例使用同一隔离引擎环境；不返回认证内容。

### 启停结果

启动失败说明实际失败阶段、被测目标、本次日志位置和已知进程退出信息；等待超时与进程已退出分别报告，不推断未观测到的底层原因。创建进程后的失败会清理本次实例，并报告清理是否成功。

停止核对实例归属，并在确认本次进程退出、CDP 端口释放后报告成功；停止失败或仍被占用时返回具体状态，不吞掉错误。同一 dataDir 的停止与重启沿用既有隔离数据，调用者无需通过更换目录来表达正常重启。

### 窗口状态

`app.window` 接收本次 `app.start` 创建的实例 `pid` 与 `action: "status" | "minimize" | "restore"`，查询、最小化或恢复该实例窗口，返回实际 `visible`、`minimized` 状态。窗口和焦点始终留在隐藏桌面。操作核对目标归属，不控制用户实例或其他进程；恢复包含该隐藏桌面内的窗口激活，使页面可接收真实可见性变化。页面的 `document.visibilityState` 和事件消费结果通过现有 CDP 观察，窗口状态回执不代替页面证据。

## 明确不做什么

不复制用户真实项目或运行记录，不预制各业务的复杂场景或建设通用夹具编排框架，不改变会话列表交互。固定历史数据不用于证明模型调用、真实 fork 或调度执行链路通过。不提供任意桌面或进程控制，不改用户模型偏好、角色覆盖或配置来源文件。

## 已定的实现方向

准备能力属于开发与验收工具，集中在现有 AppLauncher 与 CLI/RPC 路径。真实项目以工作台服务注册，后续状态使用现有产品入口产生；固定夹具满足应用现有身份、会话归属、历史和持久化契约。业务查询、渲染和交互不增加为夹具放行的特殊逻辑。配置和中文材料按 UTF-8 读取，返回值及日志不包含认证内容。
