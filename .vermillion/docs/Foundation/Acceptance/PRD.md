# 隔离实例准备

## 要做什么

`app.start` 支持可选的 `fixture: "session-tree"`。调用者提供独立 `dataDir` 与 CDP `port`，一次完成隐藏桌面实例启动、独立测试项目创建与注册、会话数据准备。成功返回时应用和数据均已就绪，可直接连接 CDP 操作工作台，无需另行注册项目、生成会话、刷新或重启。

`session-tree` 提供一个父会话、一个归属正确的子会话及一个没有子会话的普通会话。列表通过正常查询与渲染路径显示这些记录，支持展开、折叠和打开会话阅读固定历史内容；准备过程不调用模型、不启动 Worker 或创建执行工单。

结果包含 `pid`、`cdpUrl`、`desktop`、绝对路径 `dataDir`、`projectPath` 和 `workspaceId`，可用于连接、查询和核对隔离范围。停止沿用 `app.stop`。不指定夹具时保留现有启动行为。

## 明确不做什么

不复制用户真实项目或运行记录，不提供其他业务夹具或通用夹具编排框架，不改变会话列表交互。固定历史数据不用于证明模型调用、真实 fork 或调度执行链路通过。

## 已定的实现方向

准备能力属于开发与验收工具；夹具满足应用现有的身份、会话归属、历史和持久化契约。业务查询、渲染和交互不增加为夹具放行的特殊逻辑。
