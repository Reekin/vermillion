# 隔离实例准备

## 要做什么

`app.start` 接收 CDP `port`，实例目录由工作台在自己的数据目录下分配，应用与 Electron 数据、引擎状态、测试项目和启动日志都放在这个目录里。启动可选择 `fixture: "session-tree"` 或 `fixture: "real-session"`，一次完成隔离窗口中的启动（见[窗口隔离](#窗口隔离)）及对应环境准备。成功返回前确认本次进程的 CDP 与工作台 RPC 就绪；选择 fixture 时，测试项目也已通过正常查询确认注册。

`session-tree` 提供一个父会话、一个归属正确的子会话及一个没有子会话的普通会话。列表通过正常查询与渲染路径显示这些记录，支持展开、折叠和打开会话阅读固定历史内容；准备过程不调用模型、不启动 Worker 或创建执行工单。

`real-session` 提供独立 Git 测试项目及起始提交，接入真实 Codex。首次准备在 dataDir 内建立独立 CODEX_HOME，只从 `codexConfigSource` 指定的目录读取运行所需配置、认证及模型目录相关文件；未指定来源时使用调用端当前 Codex 配置目录。复用调用端可用的引擎程序及连接配置，历史、数据库、日志与其他可变状态均写入隔离目录，不复制用户会话、工单或项目。模型目录可用后返回；不自动发送模型消息、创建设计会话或派发 Worker。调用者通过现有 GUI/CLI 创建本单所需真实会话和工单，停止、重启、fork 与继续发送沿用正常产品行为。

重启时传入上次返回的 `dataDir`，沿用已有隔离配置、Git 历史、注册项目和会话，不重新生成或覆盖；`dataDir` 只接受工作台分配的实例目录。准备所需条件缺失时返回具体原因，不能以空模型目录或固定历史后端代替真实环境成功返回；创建进程后准备失败则停止该次进程。

结果包含 `pid`、`cdpUrl`、`desktop`（Windows 隐藏桌面名称，macOS 为空）、绝对路径 `dataDir`，fixture 另返回 `projectPath` 和 `workspaceId`，真实环境另返回 `codexHome`；可用现有 `runtime.info` 核对所运行构建。停止沿用 `app.stop`。不指定 fixture 时不预置测试项目，调用者按隔离规范自行提供环境。

### 候选与连接目标

启动明确指定被测源码 checkout 或发布产物目录，并绑定预期构建身份。源码候选在指定目录准备并核对验收所需构建产物；产物缺失、过期或实际运行身份不符时不返回验收就绪。当前工作目录或全局 CLI 的安装位置不替代被测目标。

成功结果同时给出被测目录、实际构建身份、实例身份和可直接复用的定向 CLI 调用信息。使用该调用信息的查询与操作只连接指定实例；目标已退出或身份不匹配时明确失败，不转接用户实例或本地离线服务。真实引擎环境返回实际使用的状态目录与非敏感环境参数，包含 CODEX_HOME、CODEX_SQLITE_HOME 等，使外部 CLI 与验收实例使用同一隔离引擎环境；不返回认证内容。

### 启停结果

启动失败说明实际失败阶段、被测目标、本次日志的关键内容和已知进程退出信息；等待超时与进程已退出分别报告，不推断未观测到的底层原因。创建进程后的失败会清理本次实例，并报告清理是否成功。新分配的实例目录在启动失败后删除；重启已有目录失败时保留该目录。

停止核对实例归属，确认本次进程退出、CDP 端口释放后删除实例目录，再报告成功；停止失败或仍被占用时返回具体状态，不吞掉错误。需要之后重启或在停止后查看实例数据时传 `keepData: true`，目录保留，用同一 `dataDir` 重启沿用既有隔离数据；最后一次停止不传该参数，目录随之删除。

### 窗口隔离

验收实例的窗口和焦点不影响用户，页面操作与截图都走 CDP。Windows 上实例运行在独立隐藏桌面，窗口和焦点都留在其中。macOS 上实例作为后台应用运行：启动和运行期间不激活，不出现在 Dock 与 Cmd+Tab，窗口从出现起就排在所有窗口之后，不获取系统焦点；窗口被遮挡时页面照常渲染并处理事件；实例不向系统发送桌面通知。macOS 实例需要用户已登录的图形会话。

### 窗口状态

`app.window` 接收本次 `app.start` 创建的实例 `pid` 与 `action: "status" | "minimize" | "restore"`，查询、最小化或恢复该实例窗口，返回实际 `visible`、`minimized` 状态。窗口和焦点始终留在[窗口隔离](#窗口隔离)范围内。操作只针对本次创建的实例，不控制用户实例或其他进程。Windows 恢复时在隐藏桌面内激活窗口，页面真正变为可见并获得焦点；macOS 最小化即隐藏窗口，恢复时窗口重新显示在所有窗口之后、不激活应用，页面焦点通过 CDP 焦点模拟获得。页面是否真的可见、事件是否被处理，要通过 CDP 查看页面本身，窗口状态回执不能代替。

## 明确不做什么

不在工作台分配的实例目录之外存放实例数据。不复制用户真实项目或运行记录，不预制各业务的复杂场景或建设通用夹具编排框架，不改变会话列表交互。固定历史数据不用于证明模型调用、真实 fork 或调度执行链路通过。不提供任意桌面或进程控制；macOS 不使用虚拟机或额外用户会话隔离验收实例。不改用户模型偏好、角色覆盖或配置来源文件。返回值和日志不包含认证内容。

测试项目通过正常的工作台注册，之后的状态都由正常产品入口产生；产品本身不为夹具增加任何特殊处理。
